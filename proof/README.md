# Ordinary proof

`ORIGINAL_PROBLEM.md` records the exact problem and original source context used
by the campaign. Its open-status assumption was stale; the controlling priority
correction is `../audits/PRIORITY_CORRECTION_2026-08-02.md`.

`PROBLEM_AND_PROOF.md` is the complete independent proof return frozen on August
1, 2026. It includes the main theorem, the direct top-threshold route, the
load-bearing reserve and cross-payment inequalities, all boundary head profiles,
and the explicit warning that the discarded unconditional residual inequality
is false.

`EXTENSIONS_AND_STRENGTHENINGS.md` records the directly proved threshold-set
lemma, quantitative slack, equality classification, zero-edge corrections, and
the one-equal-edge theorem. Threshold-set nonnegativity is not claimed as a
stronger conclusion than graphicality. `EXTENSIONS_ERRATA.md` preserves the
correction sheet that was part of the independent extension audit.

The priority-corrected manuscript provides the publication exposition. These
proof files remain independent text-level references used for mathematical
comparison and provenance.
