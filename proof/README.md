`PROBLEM_AND_PROOF.md` is the complete corrected proof return frozen on August 1, 2026. It includes the main theorem, the top-threshold strengthening, the load-bearing reserve and cross-payment inequalities, all boundary head profiles, and the explicit warning that the discarded unconditional residual inequality is false.

`EXTENSIONS_AND_STRENGTHENINGS.md` records the stronger arbitrary threshold-set theorem, quantitative slack, equality classification, zero-edge corrections, and the one-equal-edge theorem. `EXTENSIONS_ERRATA.md` preserves the correction sheet that was part of the independent extension audit.

The canonical post-literature manuscript will provide the publication exposition. These proof files remain the independent text-level references used for exact manuscript comparison.
