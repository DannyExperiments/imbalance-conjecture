# Contributing

Please distinguish among:

- an error in the ordinary proof;
- an error in a finite checker;
- a literature or priority source;
- a manuscript or repository defect; and
- a formalization contribution.

A mathematical objection should identify the first invalid inference and provide either a proof repair or an exact counterexample. A priority claim should cite a primary source with an exact theorem and hypotheses. A formalization contribution must pin Lean and Mathlib, build without proof holes or custom axioms, and state its exact theorem scope.

Do not open issues containing credentials, private task URLs, or unpublished third-party files.
