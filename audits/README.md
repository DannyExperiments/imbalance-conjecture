# Audits

The private evidence warehouse preserves the raw model returns byte-for-byte. This directory gives a public-safe adjudication of the controlling evidence.

- `MATHEMATICAL_AUDIT.md`: independent adversarial proof-audit verdict and repaired boundary cases.
- `LITERATURE_PRIORITY_AUDIT.md`: current-open-status and novelty findings through August 1, 2026.
- `CLAIMS_EVIDENCE_MATRIX.md`: claim-by-claim evidence and nonclaims.

These are AI-generated audits, not human peer review. Their raw source hashes are recorded in `PROVENANCE.md`.
